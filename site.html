Cards. Apps. Gestures.

OpenWebOS brings an OS-in-a-browser experience with an app drawer, windowed apps, and a Cards Overview for multitasking. If you want builds hosted on GitHub Pages, use Get OS.

Cards Overview: swipe up from the bottom-left or bottom-right corner on touch devices. On Mac trackpad, do a quick swipe up near the bottom corners to open overview. You can also map the OpenWebOS Key action to Open Cards Overview in Settings.

Quick tips

Cards Overview
Swipe up from bottom corners (touch). Trackpad wheel gesture is supported while avoiding in‑app scrolling.
OpenWebOS Key
Press the Meta/Command key to run your configured action (now includes “Open Cards Overview”).
Customize
Use Settings to toggle features and configure shortcuts. Your changes persist via local storage.

About

OpenWebOS is an experimental project exploring what a browser-based operating system can look and feel like. Built entirely with web technologies, it runs entirely in your browser with no server-side processing.

The project is open source and maintained by the community. Contributions are welcome!
