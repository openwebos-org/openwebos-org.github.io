About

OpenWebOS is an experimental project exploring what a browser-based operating system can look and feel like. Built entirely with web technologies, it runs entirely in your browser with no server-side processing.

Features include biometric authentication via WebAuthn, a full UNIX-like terminal, file management, media playback, a Siri-like voice assistant, and a customizable desktop environment with wallpapers, accent colors, and widgets. The project is open source and maintained by the community.
